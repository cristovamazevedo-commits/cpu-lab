O que é um Processador?

O processador (CPU) é o "cérebro" do computador. Ele busca instruções na memória, decodifica e executa operações a bilhões de vezes por segundo.

Ciclo de Instrução

Toda instrução passa por fases bem definidas. Veja animado o caminho percorrido dentro da CPU.

📋 Fases do Ciclo
1
🔍 FETCH
PC → MAR → Memória → MDR → IR
A CPU busca a instrução na memória usando o endereço do PC.
2
🔓 DECODE
A Unidade de Controle analisa os bits do IR para identificar a operação e os operandos.
3
📥 FETCH OPERANDS
Se necessário, busca dados adicionais da memória ou registradores.
4
⚡ EXECUTE
A ULA executa a operação aritmética ou lógica especificada.
5
💾 WRITE BACK
O resultado é escrito no registrador de destino ou na memória. PC é incrementado.

Pipeline de Instrução

Pipeline permite executar várias instruções simultaneamente, sobrepostas em diferentes estágios — aumentando o throughput drasticamente.

⚖️ Sem Pipeline vs Com Pipeline
❌ Sem Pipeline
Ciclos: —
✅ Com Pipeline
Ciclos: —
📊 Ganho de Desempenho
Speedup = n × kn + (k − 1)
onde n = nº de instruções, k = estágios do pipeline
Instruções (n):4
Estágios (k):5
Ciclos sem pipeline:20
Ciclos com pipeline:8
Speedup:2.5×
⚠️ Hazards — Problemas do Pipeline
🏗️
Structural Hazard
Conflito de recursos de hardware. Ex.: duas instruções precisam da mesma unidade funcional ao mesmo tempo.
✅ Solução: Duplicar unidades (ex: múltiplos ALUs)
📊
Data Hazard
Uma instrução depende do resultado de outra ainda no pipeline.
✅ Solução: Forwarding / Stall
ADD R1, R2
SUB R3, R1 ← depende de R1!
🔀
Control Hazard
Desvios condicionais (branches) causam incerteza sobre qual instrução buscar a seguir.
✅ Solução: Branch Prediction

Hierarquia de Memória
